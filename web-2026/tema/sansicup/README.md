# Tema SanSi Cup

Tema de una sola página para sansicup.umss.edu.bo. La página de inicio usa la plantilla `evento`:
todos los datos del concurso (fechas, costo, enlaces, cronograma) están en el encabezado YAML de la
página, y el texto de «¿Qué es la SanSi Cup?» es el contenido Markdown de esa misma página.
Cualquier otra página usa `default` (título y texto sobre papel crema).

Tipografías Fraunces, Barlow Condensed y JetBrains Mono con licencia SIL OFL (`fonts/OFL-*.txt`).
